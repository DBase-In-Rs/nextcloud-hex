# Nextcloud Hex & Markdown Viewer

Minimal installable Nextcloud app scaffold for:

- binary hex preview
- Markdown reading

## Local install

```bash
sudo -u www-data php occ app:enable hex
```

## Next step

Right now this is an installable app skeleton with metadata.
The next development step is to add Files integration so:

- `.md` opens in a Markdown reader
- binary files can open in a hex viewer panel
